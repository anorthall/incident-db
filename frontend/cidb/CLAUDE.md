# Design

- You MUST ALWAYS refer to the shadcn UI documentation for design guidelines: https://ui.shadcn.com/docs/primitives/overview
- You MUST NEVER implement custom CSS styling for components that are already provided by shadcn UI.
- You MUST ALWAYS use shadcn UI components and extend them as needed for custom functionality.
- You MUST ALWAYS ensure that the design is consistent across the application by adhering to the shadcn UI design system.
- You MUST ALWAYS test the responsiveness of the design on various screen sizes and devices.

# Procedure

- Always check any links, buttons, and forms for accessibility and usability.
- Ensure proper use of semantic HTML elements for better accessibility.
- Ensure any active elements have the cursor pointer CSS property via Tailwind CSS.
